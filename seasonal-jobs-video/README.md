## التعديل وإعادة التصدير

- النصوص والتوقيت في `src/app.js`، والتصميم في `src/style.css`.
- المتطلبات: Node و Playwright (Chromium) و ffmpeg و Python مع numpy.

```bash
node render.js 1080 1920 raw/reels.mp4      # يكتب أيضًا raw/reels.sfx.json
python3 audio.py raw/reels.sfx.json raw/track.wav
ffmpeg -i raw/reels.mp4 -i raw/track.wav -c:v copy -c:a aac -shortest out.mp4
```

لمعاينة لقطات ثابتة: `node render.js 1080 1920 shot --stills 5,18,30`
